
# Tic Tac Toe Game

## About Project
A Tic Tac Toe game developed using HTML, CSS and JavaScript.

## Features
- Two Player Game (X and O)
- Winner Detection
- Draw Detection
- Scoreboard
- New Game
- Reset Score
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
